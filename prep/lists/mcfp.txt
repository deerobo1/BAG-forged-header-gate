# MCFP captures for LitCVit's MCFP classes (the paper names the families but
# not the captures). Malware: the 2018 batch 341-347 holds one capture per
# named family (Stratosphere's malware list, checked 2026-10-27); "Botnet" is
# the only capture that list labels with a generic botnet family (157-1).
# Benign: the CTU-Normal captures with full pcaps (13 is empty, 4/5/6/10 are
# DNS-only or have no pcap). LitCVit's "600 benign PCAP files" can't be matched.
#
# Pcaps only: never the .zip files (live malware binaries). The CTU server and
# this link give ~300 KB/s in total, so most pcaps are taken as prefixes: 64 MB
# of malware, 32 MB of normal. Remove the numbers to extend.
#
# The 2018 captures (341-347) were recorded on a shared lab segment: most of
# their packets are other machines' IPv6 multicast, IGMP and SSDP. Only flows
# with the infected host named in each README count as malware
# (baselines/header_payload.py, mcfp_class).
